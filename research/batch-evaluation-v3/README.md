# 引语/时间作用域收敛：批量方法v3（仅离线）

## 已解决的开发例

1. “我现在被堵在门口，对方说‘我要打你’”：外层当前用户被堵证据与施害者直接话语绑定，risk由unknown改urgent。
2. “有人砸东西并拦住我，这就发生在现在”：仅将紧邻且明确指向这一事件的后置时间绑定，unknown改urgent；“昨天发生，现在写日记”不套用。
3. “朋友说‘爸爸正在掐我’，她已经安全到家”：明确第三方单一引语与紧邻完整解除陈述绑定，只排除引语内身体伤害急性匹配，urgent改unknown。紧邻下一整句的相同解除也支持；中间有另一实体/句子则不跨越。unknown并非安全结论，保留needs_clarification元数据，不强迫每次追问或危机模板。

新增threat_scope.py集中表达说话人、受影响者、时间、解除与依据。当前威胁和旧急性匹配共用该作用域，而非任意扩大关键词列表。RuleThreatScopeJudge是有限规则基线；ThreatScopeJudge只是后续语义适配器契约，不是已训练或已调用的LLM。

回归覆盖：过去/假设/小说中的施害者引语、明确对别人说话、否定、事件时间与无关现在的区别、说话人切换、相邻解除、解除之后仍受困、歧义指代及新自身危险。自伤/过量服药不进入这一身体伤害排除规则；旧未解除急性证据与新的当前威胁保持独立。没有以降低敏感度换取本组三例通过的全局过滤。

## 仍失败与结构性边界

development-diagnostics.json保留一个跨轮失败：上一轮朋友转述“爸爸正在掐我”，本轮“朋友已经安全到家”，仍urgent；开发者预期不再确定为当前急性。现实现逐条消息扫描，缺少跨消息事件ID、实体同一性、解除时间及持续危险关系，无法仅凭本轮关键词可靠撤销历史证据。此处保守保留可能造成误报，不包装为已解决。

多层转述、多人共享代词、隐喻、间接威胁和隐含时序也超出规则保证范围。固定短句通过不代表真实对话安全；现有risk字段只有urgent/ordinary/unknown，needs_clarification并不等于已实现可靠的分级处置。

## 下一步语义接口方案（未实现能力不冒称完成）

将既有ThreatScopeJudge扩为逐事件输出：event_id、source_message_id、原文span、speaker/actor/affected_entity、asserted/negated/quoted/hypothetical、time_relation、resolution_target及证据span。跨轮解除必须引用同一事件与同一受影响主体；无法支持时输出insufficient，不把LLM自报confidence当校准概率。校验器验证span与消息身份，独立急性约束不由模型自由覆盖。

动作层分开：明确当前直接危险→安全支持；明确已解除第三方事件→正常支持但保留未知；实质影响安全处置的未定主体/时间→一个必要澄清或条件式安全支持。该分级需要独立专业标签和错误代价审核；当前仅已有规则接口，不宣称部署了语义判定模型或校准决策。
