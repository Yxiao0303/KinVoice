## 实施与可用范围

实施拆分：① 类型与来源约束；② 修订失效传播及支持选择；③ 现有页面卡片/纠正；④ 合成回归、浏览器及历史审计。此次完成工程离线闭环，不把专业审阅、数据建设或训练计划视为已完成。

新 `POST /support/student` 是现有认证、限流、请求上限、退出失效与本地同源保护下的**独立离线路径**。无 provider 参数或远程分支；即使全局配置 remote，也不会调用模型。旧收费入口不接受带 student 配置的新请求（422），新入口不使用旧剩余预算。

- 首场景：成年大学生学业受挫与家庭期待。必须同时 `eligible=true`、学段 university、单独 `adult_confirmed=true`；大学学段不推断成年。
- 初中学习适应/家庭、高中考试升学是 `STAGES` 中明确的 design_only 配置，仅内部函数合成测试；HTTP 入口一律拒绝（403），即使勾选成年也不放行。
- 新页面路径须主动勾选；切换路径先清空会话与纠正记录。只是本地内部演示，不是实际年龄核验系统或招募流程。
- 生活学习影响、当前需要、危险线索、证据、未知项、支持动作进入结构化响应；不作疾病诊断，不自动决定选科、录取或就业。

## 方法定义：候选机制与实际实现分开

令每条用户来源为 `(message_id, digest(text))`，事件容器 ID 为其确定性摘要。字段判断为 `(field, value, status, evidence, revision, supersedes)`。适配器产出先过类型、允许值、完整来源覆盖、事件 ID 与原话引用检查；适配器不能声称用户已经确认，也不能自造纠正版本。来源匹配仅证明引用存在，不证明语义蕴含。

复用 `ReviewEntry / validate_reviews / reduce_reviews`，按同字段、同来源的最高 revision 应用确认、更正或撤销。确认/更正的依据明确是**用户复核行为**，不是原句自动支持新值。撤销整个事件将其 active=false，并把该事件依赖的压力、主体、时序、影响置 unknown/revoked，移出下一步依据；不修改原消息，不全局清除其他事件。原消息仍进入独立风险检查，撤销普通事件不能解除当前危险。

当前需求来源区分本轮明确文字、用户选择与已有意愿复核；动作遵循独立安全/必要风险澄清 → 当前明确意愿 → 用户选择。未知可留未知，不强制问卷。支持动作含倾听、整理、必要澄清、草稿、小步骤、选项整理。写作只对已有有限模板覆盖的目的直接提供文本；目的不明先澄清，不能宣称完成任意写作。用户拒绝计划时不因菜单选小步骤而强推。高影响选择只整理选项，不代做决定。

**实际基线**：`RuleStudentJudge` 是可替换、保守的词面判断；`StudentJudge` 是类型化接口，非已训练模型。一次消息是一个未合并事件容器，多主体、混合时态及复杂转述保留不确定。来源、撤销与危险事件机制复用现有 C-CARE；未另造持久记忆或训练数据库。`student_subject` 实为待核对的提及主体，不能声称已精确理解“谁对谁做了什么”。输出为明确标识的固定规则模板，不是 LLM 的真实表现。

**拟研究机制**：可用同一基座或轻量多任务模型预测字段/证据/事件链接，再以确定性失效传播和意愿/安全可行集合约束动作。需分别比较规则、强单步、资源匹配通用多步、常规多任务+记忆与该候选；消融来源失效、动作约束和学段条件。收益应来自独立的任务完成/依据一致性指标，不能用更多 token 或总是倾听冒充收益。没有本轮训练、微调、概率校准、首创或优势结论。

## 关键验收与真实限制

通过判据：来源不可伪造；同来源更正、撤销可跨轮回流；事件撤销级联但不影响不相关事件/独立安全；明确写作不固定倾听；用户拒绝优先；学生接口永不调用 provider；未成年设计配置不通过 HTTP；卡片无 HTML 注入，清空/退出/旧响应隔离沿用并回归。无效适配器产出返回带失败码的保守回退；仍保留独立安全支持。

尚未完成：一般事件抽取/复杂主体时序、自动自然语言跨消息纠正绑定（目前用明确卡片复核）、持续时间结构抽取、任意写作与个性化学业计划、跨会话记忆、专业验证的资源目录、真正多任务判断训练与排序器。没有因“关键词未命中”认定安全。模板和规则可能过度保守或漏判，不用于真实学生求助。初高中仅有设计措辞/配置测试，不是适龄验证。

数据只在页面内存及请求内流转；清空、切换路径、退出删除本页记录与复核。撤销判断不等于删除原始消息；页面已明示。账号数据库不保存对话；不默认家校分享，不采集姓名学校精确生日，不承诺绝对保密。危险时提供可信任支持人/当地紧急服务方向，不默认联系涉事家长，不虚构热线或已通知他人。更细适龄表达、同意、服务商数据规则需专业/隐私审查，不写未经核验的法定年龄阈值。
