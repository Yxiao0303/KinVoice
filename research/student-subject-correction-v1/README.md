# 已见 P1 主体纠正缺陷关闭（离线开发回归）

本轮只修复 `student-intent-p2-v1/p1-counterexample.json` 中发现的明确缺陷。该原反例、P2模型/配置/标签/冻结/逐例预测保持原样；`seen-replay.json` 是新代码对原输入的已见开发回放，不是重新评估P2候选。没有收费调用、真实学生数据、训练模型上线或效果提升主张。

## 修复前后

旧行为：“这次考试后妈妈说我不努力” → “那句话是我爸说的”，两个事件都 active，旧主体仍留在策略依据中。

新行为：唯一可绑定的旧发言事件退役，旧压力/主体/时序/影响判断均 unknown/revoked，移出 basis_event_ids；新主体 father 标 confirmed，引用纠正消息原句，并通过 supersedes 指向旧事件。其他字段不自动迁移，以免把“妈妈导致家庭压力”等依赖错误归属的结论转给爸爸。新记录仍可在现有卡片上更正/撤销。

## 有界绑定规则

- 新增后处理 `student_corrections.py`，在可替换判断器输出的类型/来源校验和显式 UI 修订之后运行；不是新训练模型或通用语义理解器。
- 当前只接受整句格式：`[更正：]那句话/刚才那句话/刚才说的那句话是{我爸/爸爸/我妈/妈妈/老师/同学/室友}说的`，或 `“明确原话片段”是{主体}说的`。必须有同一请求内的原消息ID和摘要。
- 只在**全部仍有效历史中恰好一个符合条件的自述发言事件**时绑定，不能因为某一条更近就选它。引用式纠正还要求原文片段匹配，重复引语不绑定。单条消息多发言/多主体或明显“又说/还说/另外/另一件”不作单事件绑定。
- 否定、第三方引用、假设不当作正向纠正；识别到纠正形态但不能绑定时新主体保持unknown，不影响其他旧事件，并提示使用对应来源卡片核对。并非所有自然语言变体均被识别。
- UI对纠正消息的主体更正优先于原始文字推断；撤销该纠正会留下未知/停用状态，**不自动恢复旧主体**。对更早来源的明确事件撤销也不会被新推测复活。
- 普通事件依赖可以失效，原始消息仍进入原有独立风险通路，不能据此清空不相关自身/第三方风险。危险与其他事件不共享全局撤销开关。

## 验证

新增七组后端开发回归：原反例与后续轮次、跨消息多事件不按最近绑定、唯一引用选择不同主体事件、多发言/重复引语、否定/转述/假设、UI更正及撤销不复活、旧或新独立危险。

浏览器E2E新增实际接口操作：自然语言更正后卡片显示爸爸、不再显示妈妈；旧依据可见失效；再撤销纠正，后续不复活爸爸或妈妈。原有退出/清空/旧响应隔离继续运行。

## 仍有的结构限制

一条消息目前仍是一个事件容器。任意代词、复杂否定、多个事件间自然语言引用、并列或省略纠正没有可靠语义链接，不能声称全部自动解决。支持范围外可用明确来源的卡片纠正，或引用唯一原话；有歧义不全局改历史。引用是否存在仍不等于真正语义蕴含。更强事件定位/链接需要独立标注与专业审阅；P2的14/16分类结果不能作为启用产品模型的理由。

独立标签、真实语义/生成对照、适龄审阅及新用途预算仍是后续依赖；本轮不跨越这些边界。原账本累计172次、预留394.866176元、剩余5.133824元未改，未合并部署。
