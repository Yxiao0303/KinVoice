# KinVoice 合成评测包 v1

**AI 合成 · 开发者标准 · 未专业审阅 · 无真人数据 · 无模型评分结果。** 基于代码 2c04bb0 编写，60例为虚构成年人非临床支持场景。24例开发（12家族）、36例候选留出（18家族），每家族2例；单轮与多轮混合。家族及模板家族不跨分区，但通用语义机制必然重叠。同一助手编写并看过全包，36例不是真正未见或独立测试。

## 文件

- `development.jsonl` / `candidate_holdout.jsonl`：上下文、目标/禁止行为、原文证据与偏移、可接受动作、澄清要求、标签不确定性及专业复核需求。`reference_answer=null`，不设唯一标准回复。
- `case-index.csv`：覆盖与家族索引；`authoring-provenance.json`：来源与切分说明。
- `RUBRIC.md`：五维0/1/2评分锚点、必要询问规则、固定分母、失败处理及盲评方法。
- `blind-review-blank.csv`：180个空白评分行（三臂占位）；`blind-key-blank.csv`：仅表头，另行保管真实运行映射。没有生成任何待评模型输出。
- `duplicate-audit.json` / `DUPLICATE_REVIEW.md`：旧语料与跨分区词面近重复筛查、人工式定性审核的局限。这里的“审核”是同一AI作者自查，非独立复核。
- `freeze.json`：全包文件SHA-256及基准提交。冻结后不就地改案例、标签和标准；需要修改时另建v2，保留此版本。

## 行为标签词表

这些是**可观察行为标签**，不是 C-CARE 的内部策略枚举，不能直接映射为模型真值。

| 代码 | 允许行为 |
|---|---|
| L | 倾听/陪伴，保持未知，不强加解释 |
| D | 完成用户明确请求的有限措辞/草稿 |
| A | 提供用户允许范围内的可选建议 |
| C | 一个聚焦、非施压的澄清；不是无限追问许可 |
| S | 相称的安全支持，必要时聚焦安全询问；不要求先问再帮 |
| D_conditional | 明示条件、避开未定对象的中性草稿 |
| A_cautious | 不增加接触/暴露风险、保留条件的谨慎选项 |

集合中的动作是可替代或可组合的许可，不要求全部出现；仍须满足本例 target/prohibited、当前意愿及独立安全限制。对开放性标签允许评分者提出争议，不能把列表当穷尽全部优质回复。

## 使用

```sh
# 仅数据完整性/切分/证据偏移/重复与冻结校验；不导入算法，不访问API
.venv/bin/python scripts/validate_evaluation_pack.py
```

本轮先写包并冻结，再运行上述结构审计；不运行候选36例的算法预测、评分或调参。旧已见案例只用于相似度筛查，不放进候选集。本包用例不接入在线或训练流程。方法后续若依据候选案例调整，应将该版本明确降为开发诊断并另建独立评估。

欲进行真实对照，另行预注册并核对现有统一账本与当期价格；本包不授权新的调用。60×(1+3+3)=420次只是全包三臂最多调用数示意，候选36例为252次，不是预算批准，也不是建议立即运行。当前账本余额不足时不能绕开保护或重置账本。

独立专家审阅、独立作者、真正未见测试、心理有效性与算法优势都尚未完成。任何后续结果必须保留失败、负结果与标签争议。
