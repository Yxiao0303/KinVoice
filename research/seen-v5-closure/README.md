## 实现边界

- `intent_scope.py` 仍为词面基线：当前明确请求 > 探索性动作启发式；同轮先确认再写时先确认；明确先听、否定、转述、未来请求不能当作当前写作授权。安全硬约束优先，unknown 不被改成无风险。
- `three_arm.py` 不再用初始化时的倾听判断覆盖最终生成策略。没有新增学习模型，没有声称语义蕴含或校准。
- `emotion_grounding.py` 只检测有限情绪词组及断言句式，依据当前自述或简短情绪陈述；区分否定、引语、历史和第三方。当前情绪与别的情绪不能互相授权。旧撤销检查仍独立存在。
- 此检查仍可能漏掉隐喻、跨句主语、复杂转述；对历史仍持续的真实情绪可能过度保守。泛指“会让人悬着”与直接赋予用户情绪的区别仍需人评；本轮回放标记不能直接算错误率。问题/条件/引语未命中也不表示安全或正确。
- D10_address_missing-02 的语义缺口、D03 历史证据错误，以及其他未充分覆盖的生成遗漏仍存在。没有对已见输出继续拟合到全部通过。
