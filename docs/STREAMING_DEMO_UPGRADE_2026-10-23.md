# KinVoice 0.5：可中止的分阶段演示

本轮把“等整轮结束后查看结果”升级为实时查看处理步骤。新网站使用 `/support/stream`；原 `/support/turn` 保留。策略仍为 `ccare-prototype-0.2`，本轮没有改变风险规则和创新主张。

## 本轮功能

| 功能 | 现在能做什么 | 不能据此声称什么 |
|---|---|---|
| 阶段进度 | 状态估计、候选生成、重写和校验开始、结束时，由后端发送真实事件 | 没有逐字显示未检查的候选，也不展示内部推理 |
| 暂停处理 | 页面关闭连接，后端检测断连后取消当前任务，释放会话占用，不再开始后续步骤 | 服务商已经收到的请求不保证停止，不保证免计费 |
| 最终发布 | 通过既有规则与模型检查后，才发布最终回复；异常时保留固定退回路径 | 模型自检不等于专业审核或临床有效 |
| 技术记录 | 导出 Markdown，含实际策略、允许策略、调用步骤、耗时、返回模型名、用量和失败码 | 不包含对话原文、引用原话、生成回复、账号和密钥；不是研究结果报告 |
| 上下文截断 | 按完整的用户—助手轮次保留最近上下文，仍受 20 条、16000 字符限制 | 没有持久记忆，也不自动保存个人画像 |
| 旧版本兼容 | 网站读取服务能力，旧后端继续使用普通接口，并说明其暂停限制 | 旧后端不会因前端文件更新而自动获得取消任务的能力 |

技术记录中，失败或暂停轮次的用量标为未知。每次导出带时间戳，保留旧文件。清空页面后，内存中的逐轮结果也随之清除。

## 本机入口

新版固定示例网站：`http://127.0.0.1:8768/`。旧版 8765 进程保留，本轮未强制结束它。

仓库路径为 `C:\Users\YYX\Desktop\KINVOICE\KinVoice`。执行 `scripts/Start-Demo.ps1 -Port 8768` 可打开新版。未指定端口时默认使用 8765；如果该端口仍是旧版，脚本会说明如何选择其他端口，不会停止占用进程。

模型版仍使用 `scripts/Start-Model.ps1` 和端口 8766。新密钥仍未提供，当前没有真实模型调用或真实连通成功结果。配置步骤见 `docs/MODEL_CONNECTION_2026-10-23.md`。

## 现场演示顺序

1. 登录固定示例网站，选择“我现在只想有人听我说”，确认虚构情境后发送。
2. 展示“准备表达”被本轮拒绝覆盖为“倾听”，并指向原话与允许策略。
3. 点击“导出技术记录（不含对话）”，说明记录来自本轮实际接口。
4. 接入新密钥后，再展示状态估计、生成和校验进度。候选未通过检查时不会提前出现在对话框。
5. 在处理中点击暂停，说明页面关闭连接后，后端检测断连并中止后续步骤；已经外发的数据不能撤回。

固定示例模式没有模型步骤，仍明确标识 1 秒展示节奏，不能用它演示模型延迟或声称真实调用。

## 工程验证与边界

离线验收标准在执行前确定：进度事件有序；原话和候选不进入进度事件；最终结果只在校验后发送；断连取消任务并释放会话；中途退出后不返回回复；缺少最终事件或乱序时不显示回复；技术记录排除对话文本；上下文保留完整轮次。

本轮后端 59 项离线测试通过，网页状态、事件解析和记录导出 15 项测试通过。网络传输在后端离线套件中被禁止。浏览器另用本机模拟服务核对进度和暂停，模拟服务没有调用外部模型。

已知风险仍包括否定表达、课程转述误报，以及没有被开发案例覆盖的隐晦危机。未重跑或替换旧开发诊断，未增加“独立准确率”或效果数字。当前阶段进度与取消任务是工程完善，不能独立宣称算法创新。

## 可核查实现

- `backend/app/ccare/streaming.py`：有界事件队列、心跳、会话复核和断连清理。
- `backend/app/ccare/engine.py`：只发送阶段元数据和策略选择，不发送候选文本。
- `backend/app/ccare/web/stream.mjs`：分片 UTF-8、事件顺序、协议和最终记录检查。
- `backend/app/ccare/web/report.mjs`：技术记录字段白名单，不导出原始对话。
- `backend/tests/test_streaming.py`：完整 ASGI 请求的断连、并发和中途退出测试。
- `tests/web-stream.test.mjs`：分片、截断、乱序、取消、隐私字段和上下文成对截断。

实现依据包括当前安装的 Starlette 0.38.6 `StreamingResponse` 源码与 [Python 的任务取消说明](https://docs.python.org/3/library/asyncio-task.html#task-cancellation)。实际行为以本机测试为准，尚未验证多进程托管或代理服务器缓冲。
