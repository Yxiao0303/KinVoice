## 产品与研究定位

服务于 18–25 岁、因亲子冲突产生情绪困扰的成年大学生，提供非临床、单方自愿的情绪支持。不是心理疾病诊断或治疗系统，不承诺获奖或心理改善。不强制父母参与、不以和解或恢复联系为默认目标。

重点研究：用户事实、当前意愿与安全线索能否经证据约束转化为更合适的支持策略。核心候选贡献是语义证据校验、受约束策略决策，以及公平可复现的评测；不是继续添加角色、声音克隆和社交页面。

### C. 结构化状态与语义证据接口

扩展现有 schemas / policy，不无谓新建重复模块。每个重要状态字段应能表达：
- 用户明确陈述、用户确认、模型推测或未知；
- 消息 ID、角色、原话区间与出处；
- 当前轮意愿与历史信息的区别；
- 信息不足和需要澄清；
- 用户纠错后旧判断的失效或更新。

原话存在只证明引用定位成功，不证明语义成立。为语义校验建立独立、可替换接口，建议使用 supported / contradicted / insufficient 三态。覆盖否定、双重否定、引用、第三方转述、假设、反讽、时间与说话人归属，以及多轮意愿变化。

先实现诚实可测的规则基线和可插拔语义判定适配器。规则无法覆盖时保留 insufficient，不冒充语义蕴含模型。未经过人工标注与校准，不把模型自报 confidence 称为可靠概率。不要为了展示进阶算法强行下载训练大模型。

语义不支持不能被机械等同为“绝对无风险”。涉及急性安全线索的澄清、保守支持与不确定性规则要独立保留，并通过离线反例验证，避免一个错误判定关闭全部安全措施。

### D. 策略约束与输出验证

保留确定性策略为可复现基线；新增明确的策略选择接口，支持后续规则、LLM 选择与学习排序器的公平替换，但不要把未训练的占位器称为已学习模型。

不变量：
- 当前明确拒绝建议优先于界面默认项和模型推测。
- 不默认劝和；沟通草稿必须符合用户当前意愿与安全边界，不自动发送。
- 涉及威胁、胁迫、暴力或急性危机线索时，使用独立安全支持路径，不泄露给家庭成员。
- 不诊断疾病，不无依据推断父母动机，不鼓励对 AI 的排他依赖。
- 状态变化能够撤销过期意愿，模糊情况允许澄清。
- 选择了正确策略不代表输出一定合规；生成后仍需校验、有限重写与安全回退。
- 决策记录展示可检查的结构化依据，不输出模型私有思维链。

专业文案的适用性标明待专业审阅；不得编造热线、机构服务或专家审核记录。

### E. 离线评测与强基线框架

建立可从命令行运行的评测入口，默认 dry-run/mock。明确区分以下配置：
1. 同一模型的强单轮心理支持 Prompt；
2. 原版 NVC（仅作为产品历史参照，不作为唯一强对手）；
3. 同模型、同信息、相近总 token / 调用上限的多步强基线；
4. 完整 C-CARE；
5. 隔离评测中逐项移除意愿约束、家庭约束或证据校验的消融条件。

所有面向真实用户的应用路径保留完整安全机制。消融不能通过普通网站参数被启用；默认也不采集真人输入。

每条结果记录 case_id、母案例 family_id、split、条件、模型及配置版本、输出状态、失败原因、调用次数、延迟及实际 usage；评测用例只用明确标记的虚构数据。失败、超时和不完整样本必须留在报告分母中。不要把 mock 输出统计成模型效果。

指标框架覆盖：策略适切性、自主权与事实保真、语义支持、无依据推断、安全遗漏与误拒、跨轮调整、调用失败、延迟与成本。需要专家判断的指标留待盲评，不靠字符串命中假装测出共情或临床效果。

生成匿名盲评表、错误分类和结果汇总工具。先支持真实数据输入再计算统计量；没有标注则明确 unavailable，不产出伪造胜率、显著性或提升百分比。

### F. 小规模测试用例与数据契约

为新模块编写小规模、明确标记 synthetic/unreviewed 的测试夹具，覆盖普通冲突、拒绝建议、意愿变更、否定与转述、边界与控制、危险线索、提示注入和数据泄露。数量以覆盖真实分支为准，不为达到数量指标批量造数据。

成对、同义改写、多轮衍生样本按母案例整体划分，不能散落到训练和测试两端。现有 8 对开发案例仍归开发集。本阶段不能声称已完成独立专家测试集。

### G. 隐私与回归保障

审查并补充认证、跨用户访问控制、清空/取消/账号删除、导出脱敏的回归测试。不得复活旧的 X-User-Id 默认身份或旧 API。演示账号和测试数据库只在隔离环境创建。

禁止将用户私密内容写入仓库、普通日志、统计遥测、评测样例或家庭记忆。新的记忆能力只能作为后续显式 opt-in 方案，不能在本次暗中开启持久化。
