## 实际结果

本机Playwright 1.62.0 + Chromium 154（Linux桌面1440×1000）跑通8组验收：

| 验收 | 覆盖与结果 |
|---|---|
| 确认/纠正/撤销 | 从实际UI展开操作区；重复确认保持revision=1，纠正与撤销递增至3，后续真实API返回angry/unknown并反映到UI，通过 |
| 生成规则回退 | 本地桩生成被禁止的候选，真实Engine拒绝；候选不出现在页面，仅显示固定回退，通过 |
| 检查器拒绝 | 本地桩verdict拒绝，真实Engine回退，通过 |
| 截断流 | 浏览器网络夹具只提供start帧、没有result；页面显示连接提前结束，不发布回复，通过 |
| 重复发送/暂停 | 连续两次表单提交只发一次请求；真实慢速本地流可暂停，之后无助手回复；新会话history/reviews为空，通过 |
| 旧响应覆盖 | 浏览器故障注入暂存完整旧API响应，在清空并完成新会话后释放；旧回复不重现，通过 |
| 退出/账号切换 | 同样将旧账号响应延迟到新账号已完成一轮之后；旧内容不出现，新请求无旧history/reviews，浏览器存储为空，通过 |
| 独立浏览器会话 | 新BrowserContext不能继承登录，进入聊天需重新认证，通过 |

截断流和延迟响应是显式浏览器故障注入，不声称自然网络已经发生这些故障；其余路径走真实本地服务。
浏览器控制台pageerror=0，测试页面向非本地地址的请求=0。测试阻断非本地页面请求；服务启动即禁用httpx真实出站传输。
API/Engine桩调用数量不是大模型调用数量，没有虚构真实token或费用。

后端136/136、前端Node测试19/19、两份站点JS语法检查通过。新增独立browser-offline CI job自动执行E2E。
首次测试脚本修正了折叠面板未展开、CSP禁止字符串求值的等待方式；网站CSP未放宽。
未发现需要重写生产会话逻辑的问题；新增离线入口、准确mock标识及回归，保留原会话实现。

## 周一（2026-10-26）可复现演示

在新检出的本分支目录，使用Python 3.12（已有虚拟环境可复用）：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-ccare.lock.txt -r tests/requirements-browser.txt
.venv/bin/python -m playwright install --with-deps chromium
.venv/bin/python scripts/check_web_e2e.py
.venv/bin/python scripts/offline_web_demo.py --port 8767
```

Windows对应使用`.venv\Scripts\python.exe`；本轮仅实际验证Linux，不宣称Windows已跑通。
如已有系统Chromium，自动测试可用CHROMIUM_PATH指定其可执行文件。无需改代理、网络白名单、密钥或模型配置。
E2E脚本自行启动/关闭随机环回端口服务；手工演示固定绑定127.0.0.1，不提供公网监听参数。
浏览器访问 http://127.0.0.1:8767 ，确认首页/会话角标显示“离线 mock”。
创建仅用于演示的虚构账号和不复用的测试密码；账号库在临时目录，正常退出服务后删除，不使用原账号/预算库。

建议五分钟流程：
1. 勾选虚构场景范围，输入“虚构场景：父母希望我回家，我很难过。”并发送。观察阶段变化、回复mock标签和技术面板桩调用说明。
2. 展开“确认或更正本轮理解”；情绪行确认两次，再发送“继续这个虚构场景。”。重复点击不会新增修订。
3. 情绪选“生气”并“采用更正”，再次发送相同继续消息；观察状态。再“撤销此判断”、发送继续消息，观察“暂不判断”。这演示操作传播，不是模型效果。
4. 新对话发送“虚构场景 [MOCK:reject]”，观察真实Engine拦截候选和固定回退。`[MOCK:verdict]`演示检查器桩拒绝。
5. 新对话发送“虚构慢速 [MOCK:slow]”，看到阶段开始后点击暂停，再开始新对话。退出账号并换一个虚构账号，确认无旧消息/操作。

`[MOCK:*]`只由独立离线脚本的桩识别，不是生产API切换参数。不要启动任何`--live`模型脚本。
手工演示结束Ctrl+C停止本地服务。自动回归额外包含延迟旧响应、截断流、账号切换故障注入，无需手工修改页面。
