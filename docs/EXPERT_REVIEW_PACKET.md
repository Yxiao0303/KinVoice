## 请审阅的范围

目标人群为 18–25 岁、因亲子冲突出现情绪困扰的在校大学生。系统提供表达情绪、澄清冲突、短暂稳定和沟通草稿，用户可拒绝或暂停。第一轮评审只用合成案例，不接触真实咨询记录。

请逐条检查 `backend/app/ccare/engine.py` 中的安全模板、四类支持策略、拒绝建议的处理、家庭不安全时的沟通限制。不要只给笼统的“可用”结论。

## 对照实验冻结表

| 项目 | 冻结内容 |
|---|---|
| 主问题 | C-CARE 是否在不损害自主权的条件下，改善亲子冲突支持质量并降低预先定义的危险回应 |
| 对照 | 强提示词单调用；等调用/等预算对照；状态+策略常见流程；完整 C-CARE |
| 消融 | 状态、策略约束、回应校验分别去除；仅离线合成案例运行，不向真实用户开放危险版本 |
| 公平性 | 同一基础模型、输入历史、检索材料和调参权限；分别记录调用数、token、费用、耗时与拒绝率 |
| 评价 | 专业人员盲评、配对评分与区间；自动评审作辅助；分开统计误报与漏报 |
| 数据 | 冻结独立测试集；开发数据不可改名成为测试数据；来源与许可逐条可查 |
| 统计 | 主指标、最小关注差异、重复次数和样本量待专业意见与先导方差确定；不凭空给功效结论 |
| 失败 | 模型报错、超时、拒绝、格式失败均计入分母；不只挑成功结果 |

真实样本量、临床量表和疗效终点尚未选定，不能用本轮 20 条开发样例代替。
