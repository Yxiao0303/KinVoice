# KinVoice 模型接入与使用

选择：DeepSeek `deepseek-flash`，非思考模式，官方 OpenAI 兼容接口。2026-10-23 核对了[模型列表](https://api-docs.deepseek.com/quick_start/pricing/)、[调用协议](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)与[非思考开关](https://api-docs.deepseek.com/guides/thinking_mode/)。选择依据是当前接口兼容性、JSON 输出及相对低的官方定价；未比较各模型心理支持能力，不声称它最优。

## 只需填密钥，再启动

当前电脑的 `backend/.env.local` 已填好接口、模型、服务商、隐私网址和超时；`KINVOICE_API_KEY=` 留空。这个文件已被 Git 忽略，不进入提交。请从[DeepSeek 开放平台](https://platform.deepseek.com/)获取新密钥，只填在本机文件中，不要发到聊天，不要复制旧 `.env` 中暴露过的值。

普通演示模式仍在 `http://127.0.0.1:8765/`，使用固定文本。模型版使用独立的 `http://127.0.0.1:8766/`，便于保留现场演示入口。

在仓库根目录执行：

```powershell
& .\scripts\Start-Model.ps1
```

脚本默认检查配置但不发出模型调用，然后启动模型网站。登录后，勾选虚构大学生情境，并阅读、勾选服务商外部处理同意，再发送消息。未勾选时不会发出模型请求。需要修改模型或密钥时，已运行进程必须重新启动才能加载新配置。

脚本要求已提交代码，创建唯一 `experiments/model-check-...` 目录，调用前保存代码哈希、成功标准与输入，调用后保存真实策略、失败码、阶段及用量；没有结果时不生成成功结论。

## 能看到哪些真实信息

- 页面顶部标识当前模型；固定示例不会伪装成模型输出。
- 右侧显示当前/历史原话位置来源、允许的支持策略，以及选择原因。
- 分别显示状态估计、候选生成、重写和校验的调用记录；收到返回不等于通过检查。
- 缺失的 token 用量记未知，失败不会冒充零成本。模型返回的版本名逐次保留。
- 无效密钥、余额不足、限流、超时和输出截断分别提示，不显示服务商原始错误体。
- 沟通草稿可在页面修改，修改不会自动发送，也不偷偷变成下一轮模型历史。

## 数据边界

模型版会向 DeepSeek 发送本轮消息、最近对话及处理所需的状态和候选回应。当前只供虚构案例内部评审。[官方隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)涵盖 API 并说明输入输出可能被处理和用于服务改进；本项目没有获得特定账户零保留或不训练的承诺。真实困扰者的数据、咨询记录和专业审阅应另行处理，不能由本次接入替代。

页面对话、令牌和草稿仅在内存保存；账号数据库不保存聊天。清空与退出不会删除服务商已接收的数据；暂停也不保证上游计算已经停止。
