# 研究回归：方法定义与差距审计

起点9193a5c，与远端原分支一致、工作区干净。本轮停止网页扩展；未修改线上Engine、安全规则、默认provider或账本。目标不是再做一个聊天入口，而是检验**证据约束的状态更新与策略决策是否比同模型强提示词更可靠**。赛道契合须另核对当届正式要求；接口接通或网站完成不能证明算法创新。

## 可比较的方法定义

输入为按时间排序、带角色/消息ID的对话H、当前意愿与用户纠正/撤销R。候选断言c=(字段,值,来源,原话)。先独立检查引用存在和来源资格P(c,H)，再得到J(c,H)∈{支持,矛盾,不足}。J可由保守规则或同一基座的结构化LLM产生；JSON合法并不保证语义正确。没有概率输出或校准声明。

新增研究用集合更新器reduce_field：每字段只使用最新有资格证据轮，当前意愿不从历史继承。令S为该轮受支持值集合、C为被矛盾值集合；若|S|>1或S∩C非空，状态=unknown/conflict；若|S|=1且无冲突，暂取该值；否则unknown/insufficient。较新不足证据不会自动继承旧肯定断言。用户修改仍由既有版本化review规则覆盖；这不是概率贝叶斯更新，也没有学得参数。未有当前证据的历史情绪不保证仍有效，该时效规则是局限，须专家明确时间窗。

策略候选A0={倾听,澄清,稳定,草稿}；独立急性保护产生{safety}，家庭安全约束排除draft，当前拒绝/倾听意愿限定listen；语义不足不允许解除独立保护。规则选择器或LLM选择器只可在A内选择，LLM不能回传扩大allowed，依据只能引用给定规则代码。最终回复仍须规则与模型输出检查；这些检查不是专家真值。

**具体增量**：research.py实现上述集合更新器、带消息角色/时间的规则包装、字符串定位对照、结构化语义响应适配器、独立约束集合及可替换策略选择适配器。build-messages/parse接收和校验结构化回包，不暗中调用网络；后续调用须复用受预算保护provider。它们在研究层，尚未进入线上默认Engine或真实主对照；本轮用离线反例验证契约。不能把接口可替换写成LLM语义能力已验证。

集合冲突拒判、来源约束和受约束决策属于已有一般思想，**没有首创证据**。本轮可检验贡献是特定任务中这些机制的定义与增量收益假设。尚缺针对证据时态、意愿修订、选择性预测/约束生成的系统文献查新和正式比较；没有为了“更AI”添加训练器。

## 差距矩阵

| 环节 | 目前实际机制 | 缺口与研究下一步 |
|---|---|---|
| 状态提取 | 真实基座LLM生成JSON和原话 | 语义真实性、误报/漏报，需独立标注 |
| 引用绑定 | 字符串定位、角色与当前轮限制 | 定位不等于支持；新增string-only对照明确返回语义未知 |
| 语义判断 | 线上RuleSemanticJudge为词串规则；新结构化LLM适配器只完成接口验证 | 无真实LLM判定对照、NLI训练、校准或专业金标准 |
| 不确定更新 | 原实现含review撤销；新增集合冲突拒判/新轮覆盖研究函数 | 仅手写反例，未验证跨轮误差积累；未接入线上 |
| 支持策略 | 线上确定性decide；研究层独立集合+规则/结构化LLM选项 | 无学习排序器、无专家策略偏好数据；规则也可能误限制 |
| 回复与检查 | LLM生成+规则检查+同模型JSON检查，有限重写与fallback | 同模型相关错误；需盲评最终文字，不能自检自证 |
| 页面与API | 工程承载、演示及防误操作 | 不是算法创新；本轮不增页面 |
| 强对照 | 既有single、多步、完整与实例消融；本轮新增冻结验证和盲评模板 | 主对照未真实执行；之前真实演示不构成效果数据 |
| 数据与评审 | 开发者虚构dev，包含已看过的反例 | 未有独立作者封存test或心理专家评分；不自行冒充 |
| 创新/赛道 | 候选研究问题可定义 | 文献查新、正式赛道规则和专家定位仍待核验 |

## 强基线与公平归因

冻结[探索协议](../research/exploratory-v1/protocol.md)与freeze.json：主要比较同模型多步通用review/revision与当前完整C-CARE，都是最多5×400，同一原始信息和最低安全提示。单轮1×400为成本参照。实际token/calls/延迟不等同，必须并列报告，失败全留分母。评审者只看原输入和最终回复，不看C-CARE的状态/策略/检查标签。

语义LLM和策略LLM尚未混入主对照；加入将改变调用分配，须给通用基线同等审阅机会另冻结，不能把新增调用收益称算法收益。现有证据整体消融不能单独证明语义模块贡献。新适配器允许后续定位/规则/LLM语义单因素诊断；本轮无真实效果数、胜率或显著性。

一条三条件最坏11调用的保守预留已超过剩余授权；最多一个主配对10调用可容纳，但不具有证明效力。具体费用假设、样本量限制及刘老师待决事项见协议。真实实验入口仍阻断，不能从普通网站绕过。

原协议数据9个母案例全部dev，不能通过重新划分变成独立test。正式封存需要独立作者和专业审核。刘老师首先确定意愿冲突标注、适切性锚点/差异阈值、安全处置、评阅与仲裁、独立母案例及功效方案；无真人研究或专业认可声明。

## 用户追加的实际轻量训练

方法审计后按用户新授权补充CPU统计学习原型：[训练计划与冻结数据](../research/training-v1/PLAN.md)、[模型卡与真实错误](../research/training-v1/MODEL_CARD.md)。只学习“当前用户倾听意愿”的证据三态，24训练/6开发/6合成留出，字符NB参数确实由训练文本拟合；不是把规则重命名为学习器。6条留出答对3条，信息不足两条全错，不能宣称泛化改善。此实验与上面的最终回复强LLM对照是不同任务，不能互相代替。无新网页、无收费调用、无线上安全修改。
