日期：2026-10-23。当前重点已调整为本地网站、演示故事与技术讲解。旧快应用继续保留，本轮没有修改其接口。

## 当前可用

- 网站入口：`http://127.0.0.1:8765/`。仅本机访问。
- 默认首页已换成完整网站，包含项目介绍、三个情境、C-CARE 路径与隐私说明。
- 登录、新建账号、对话、暂停、清空、退出使用新接口。对话与令牌只在页面内存；后端账号数据库不存聊天。
- 技术讲解面板展示实际接口返回的策略、状态、来源和调用数。
- 当前是 `demo` 模式：固定模板、零模型调用，界面明确标示。一秒显示节奏便于演示暂停，不能用它衡量模型响应速度。
- 移动宽度布局可操作；仅适配浏览器尺寸，没有开放手机局域网访问。

## 启动

当前电脑已有依赖环境。仓库根目录执行：

```powershell
& .\scripts\Start-Demo.ps1
```

脚本复用已运行的演示服务；无服务时启动隐藏的本地进程。不会自动安装依赖、读取旧密钥、杀死占用端口的其他程序或更改系统策略。

新电脑需要 Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-ccare.lock.txt
.\.venv\Scripts\python.exe backend/start.py --mode demo --port 8765
```

随后在浏览器打开上述地址。浏览器里可创建只用于演示的账号。当前机器另有人工测试账号，凭据仅放本地交付说明，不写入仓库。

## 现场演示：约 90 秒

1. 打开首页，说明目标人群和“先理解处境，再决定怎样回应”。
2. 点击“进入答辩演示”，登录，确认使用虚构大学生情境。
3. 第一例：专业选择，发送后指向“澄清事实与需求”。
4. 清空。第二例：拒绝建议，即使选择准备表达，实际策略也为倾听。
5. 清空。第三例：家庭不安全线索，请求草稿被限制，实际策略为倾听。说明这条保守规则还需要专业审阅。
6. 指向“模型调用 0”与固定示例标签。说明今天验证的是流程和交互，模型效果需后续实验。
7. 可另填一条虚构文本，发送后立即暂停，再清空，展示用户自主控制。完成后退出。

每个独立案例前要清空。后端会考虑历史用户消息，保留旧案例可能影响下一例策略，这属于预期行为。
