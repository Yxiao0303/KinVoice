## 当前电脑的使用方式

固定示例网站：http://127.0.0.1:8765/ 。演示账号为 `review_local`，密码为 `local-review-only-2026`，仅供本机虚构案例测试，请勿复用真实密码。

新模型配置位于 `C:\Users\YYX\Desktop\KINVOICE\KinVoice\backend\.env.local`。只需填 `KINVOICE_API_KEY`；接口与模型已准备好。密钥不要发到聊天。

填好后从仓库运行 `scripts/Start-Model.ps1`，模型网站地址为 http://127.0.0.1:8766/ 。当前因缺密钥未启动该模式，也未验证账号余额、真实网络调用或生成质量。可先用 `scripts/check_model.py --live` 执行一条内置虚构案例的连通检查，最多 5 次调用，自动保存成功或失败记录。
